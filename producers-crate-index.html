About The Suite
Architecture
Browser Native
Every app is a single HTML file. No install, no server, no build step. Drop the file in a browser and go.
Audio Processing
Web Audio API
All audio analysis runs locally in your browser using the Web Audio API. Your files never leave your machine unless you choose to use AI features.
AI Integration
Anthropic Claude
AI-powered features use Anthropic's Claude API directly from your browser. Bring your own API key — nothing is proxied through any third party.
